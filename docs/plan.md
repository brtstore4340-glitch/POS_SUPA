# Project Plan

## 1. Objective
Create a secure, scalable web application using React, Vite, and Supabase, hosted on Vercel.

## 2. Milestones
1.  **M1: Foundation Setup:** Initial project scaffolding, Supabase schema, and a basic auth UI.
2.  **M2: Local Verification:** All local build and test scripts pass. Smoke tests are successful.
3.  **M3: Deployment & Preview:** Production and Preview deployments are successful on Vercel.
4.  **M4: Final Review:** Gatekeeper review and sign-off.

## 3. Branching Strategy
-   `main`: Production branch.
-   `develop`: Staging/preview branch.
-   `feat/*`: Feature branches for new development (e.g., `feat/auth-ui`).
-   `fix/*`: Branches for bug fixes.
